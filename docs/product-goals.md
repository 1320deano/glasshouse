# Deano: product vision and goals

Updated: 16 September 2026.

Status: discovery draft, based on Christopher's answers to questions 1–5. Question 6 was answered N/A; questions 7–12 remain unanswered. The conversation is paused until Christopher returns. This records the intended direction, not a claim about current capabilities or an instruction to begin implementation.

## Vision

Make the full potential of vibe coding accessible to everyone, including people with no technical understanding. Deano should become the main and only tool they need to use to run coding agents and build their projects.

## The problem that prompted it

Christopher struggled to manage multiple agents working in parallel and understand what each was doing in the context of the wider project. He wants simple, non-technical explanations, one place to manage all his agents, and a view of how the project evolves over time. He also wants to create his own agents through the Potting Shed.

## First audience

Vibe coders, especially people with limited or no technical knowledge. The intended experience should let them use agents fully without requiring them to understand the underlying code.

## Confirmed product goals

1. **Bring agent work into one place.** Users should be able to run and manage multiple agents through Deano.
2. **Explain each agent's contribution.** Show what each agent is doing in simple language and how that work relates to the wider project.
3. **Show the project evolving.** Help users follow progress and changes over time, beyond an individual agent's current task.
4. **Support an ongoing conversation about the work.** Users should be able to watch agents, ask questions, and give further prompts as work progresses.
5. **Let users create and run their own agents.** The Potting Shed is part of the intended building experience.
6. **Make Deano the primary working environment.** The ambition is for users to carry out their agent-driven building work here, rather than needing to manage it across several tools.

## Intended everyday experience

Open Deano → run agents on tasks → watch their work → ask questions and give further prompts → track project progress. Create agents and run them as part of that same experience.

This sequence captures Christopher's desired workflow. Screen layout, detailed controls, and the exact relationship between created agents and existing helper exports remain to be worked out.
